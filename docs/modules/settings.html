Module on/off switches have no accessible name SE1 · critical

Each switch is a button with no text, no aria-label, no title and no icon class. A screen reader cannot use it — and neither could the audit, which pressed all fifteen and disabled fifteen modules of a running system.

the audit's own PATCH log: modulesEnabled {patients:false, …}

The session token is in localStorage AND in an HttpOnly cookie AUTH-TOKEN · critical

The Application panel shows the same JWT in two places: a cookie marked HttpOnly — which is correct, JavaScript cannot read it — and a token key in localStorage, which any script running on the page can read with one line.

Holding it in both cancels the protection the cookie provides. The point of HttpOnly is that a script injected through any route — a dependency, a stored value rendered as HTML, a browser extension — cannot reach the session. With the token also in localStorage, it can.

The cookie also carries no Secure flag, so it will be sent over plain HTTP.

node e2e/devtools-extra.mjs — Application panel: localStorage key `token` matches the JWT shape; cookie `token` HttpOnly · no Secure · SameSite=Lax

PARTLY WITHDRAWN — The app shell repaints for things that happen inside the module SETT-SHELL · low

34 actions caused App, Navigation or NavLink to re-render. The worst is 169× in a single action. The sidebar is not part of this module and has no reason to repaint when a table pages or a filter changes — this is one memoisation gap in src/App.jsx, and every module pays for it.

Retracted 10 August — measuring error. This count came from e2e/profiler.mjs, which counted every fiber whose actualDuration was above zero. React leaves that value on a fiber after its last render, so a component that bailed out of a commit still carried the cost of whenever it did render, and the walk counted it again on every commit. The tool now compares actualStartTime against the end of the previous commit and reports self time with children subtracted. Re-measured on Queue — the module with the largest number here — three keystrokes produce App ×16 and Navigation ×16, and no NavLink renders at all: the memoisation in src/App.jsx (commit 15c804d) is working. The shell does still re-render once per commit, which is worth its own look, but it is not the hundreds this row claimed.

Correction to an earlier claim in this report: profiler counted fibers that did not re-render

measured: NavLink re-rendered 169× (28.6 ms) — the app shell should not repaint (×9)
