FIXED — the 429 KB spreadsheet parser loaded for everyone who opened Laboratory LAB-XLSX · fixed

BulkImportDialog pulls in xlsx, the heaviest dependency in the application, and it exists so an administrator can occasionally import a catalogue. It was imported statically by both Laboratory and Radiology, so every visitor paid for it on page load.

It is now lazy() and gated on showImport. The gate is the part that matters: a lazy component fetches its chunk the moment it renders, and this dialog was rendered on every page with open={false} — so lazy() alone would have changed nothing while appearing to fix it.
